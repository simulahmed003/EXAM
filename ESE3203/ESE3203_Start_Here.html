24-hour priority list

You answer 3 of 4 questions in each part, so each part has its own list. Study down both lists until the green pass line: about 3 h for Part A and 3 h for Part B, which leaves time for sleep and a last read of the one-shot notes. Alternate between parts (A block 1, B block 1, A block 2 …) so neither is left short. Chance: how often the topic came up, newer papers weigh more (2023 ×6, 2022B ×5, 2022 ×5, 2021 ×3, 2020 ×2, 2019 ×1). Covered: share of that part's past-paper marks you have studied once you finish the row.

Retake tip: read the Concept Primer first (30 minutes). This course is almost all theory with diagrams, and the same questions repeat word for word: desalting and distillation (A3), reforming reactions (A4), delayed coking and FCC (A5), hydrotreating (A6), the amine process (B5), the LNG plant (B6) and separators (B3). Learn the memory tricks and practise each diagram once. The short numericals (API gravity, viscosity blend, VI, porosity, Darcy flow) are easy marks and each has a calculator.
