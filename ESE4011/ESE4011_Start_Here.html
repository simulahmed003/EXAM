24-hour priority list

You answer 3 of 4 questions in each part, so each part has its own list. Study down both lists until the green pass line: about 4 h for Part A and 4 h for Part B, which leaves time for sleep and a last read of the one-shot notes. Alternate between parts (A block 1, B block 1, A block 2 …) so neither is left short. Chance: how often the topic came up, newer papers weigh more (2022 ×1). Covered: share of that part's past-paper marks you have studied once you finish the row.

Only one paper (2022) exists, so every topic has the same chance; the plan therefore puts easy topics first. The fuel cell block (A7–A12) is one big family: learn the comparison table in the A10 memory box and you can answer most of Section A Q3 and Q4. The two numericals (B2 capacitors, B9 XRD) are quick sure marks with the calculators.
